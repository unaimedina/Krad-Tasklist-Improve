## Why this matters

The Tasklist extension's data is the output of the `improve` skill: an index `plans/README.md` with a
status table, and one Markdown file per task `plans/NNN-slug.md`. This plan writes the pure module that
finds, parses and edits those files without losing anything the user or an agent wrote. The tab
(plan 003), the runner (plan 004) and the auto-run scheduler (plan 005) all depend on it; a parser that
mangles a hand-edited table would corrupt the user's plans.

```ts
import type { PlanSet, Task, TaskStatus } from "./types.js";

/** plans/ if it has README.md or NNN-*.md files, else advisor-plans/ likewise, else null. */
export function findPlansDir(root: string): string | null;

/** Reads the folder: every NNN-*.md file merged with its index row. Never throws for content problems;
 *  pushes a message to `problems` instead (missing index, row without file, unparsable table). */
export function loadPlanSet(root: string): PlanSet;

/** Pure parsers (exported for tests). */
export interface IndexRow { id: string; title: string; priority: string | null; effort: string | null;
  dependsOn: string[]; status: TaskStatus; statusNote: string | null; line: number; }
export function parseIndex(text: string): IndexRow[];
export function parsePlanFile(file: string, text: string): Omit<Task, "status" | "statusNote">;
export function parseStatus(cell: string): { status: TaskStatus; note: string | null };

/** Returns the index text with the Status cell of row `id` replaced; every other byte unchanged.
 *  If no row has that id, appends a row at the end of the table built from `fallback`.
 *  Status cell format written: "DONE", "BLOCKED (reason)", "REJECTED (reason)". */
export function setStatusInIndex(text: string, id: string, status: TaskStatus, note: string | null,
  fallback?: { title: string; priority: string | null; effort: string | null; dependsOn: string[] }): string;

/** Reads, edits and writes plans/README.md (creates a minimal index if absent). */
export function writeStatus(set: PlanSet, id: string, status: TaskStatus, note: string | null): void;

/** Tasks whose status is TODO and every dependency is DONE, ordered by id. Dependencies that name no
 *  known task count as unmet. */
export function runnableTasks(tasks: Task[]): Task[];

/** Creates plans/NNN-<slug>.md from a short title (next free id, slug from the title: lowercase ascii,
 *  non-alphanumerics → "-", max 40 chars) with the skeleton below, adds a TODO row to the index, and
 *  returns the new file path. Creates plans/ and the index when missing. */
export function createTask(root: string, title: string): string;
```

Rules the implementation must follow:

- **Table detection**: the first Markdown table whose header row contains (case-insensitive, trimmed)
  `Plan` and `Status`. Map columns by header name: `Plan`, `Title`, `Priority`, `Effort`, `Depends on`,
  `Status`; any may be missing except Plan and Status. Skip the `|---|` separator row.
- **Plan cell**: first `\d{3}` match (works for `[001](001-x.md)` and `001`).
- **Depends cell / bullet**: every `\d{3}` match; `—`, `-`, `none`, empty → `[]`. In plan files read the
  `- **Depends on**:` bullet and take `\d{3}` matches **only from file names** (`plans/001-x.md`), so a
  date or SHA is never read as an id: use the regex `/(?:^|[\/\s(,])(\d{3})-[a-z0-9-]+\.md/gi` and also
  accept bare ids separated by commas when no `.md` appears.
- **parseStatus**: strip `*`, `_`, backticks; uppercase; the status is the longest of `TASK_STATUSES` the
  text starts with (`IN PROGRESS` before others); note = rest without leading `(`, `—`, `-`, `:` and
  trailing `)`, trimmed, `null` when empty. Unknown → `TODO` with the whole text as note.
- **Merging** in `loadPlanSet`: files `/^(\d{3})-(.+)\.md$/` in the folder are tasks; title from the
  first line matching `/^#\s+Plan\s+\d{3}\s*:\s*(.+)$/`, else the index title, else the slug. Priority,
  effort, risk from the `## Status` bullets (`- **Priority**: P1`), falling back to the index cells.
  Status always from the index row; a file without a row is `TODO` plus a problem
  `"003-foo.md has no row in README.md"`. A row without a file adds a problem and no task.
- **setStatusInIndex** must preserve: line endings (`\r\n` if the file uses them), the other cells,
  and the cell's padding width when the new text fits (pad with spaces to the old width).
- Never throw on bad content; only real I/O errors may throw from `writeStatus`/`createTask`.
